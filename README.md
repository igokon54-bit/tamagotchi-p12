# 🐣 Тамагочи P12 для Kozen P12 (Android APK)

Полнофункциональное автономное приложение-Тамагочи с процедурной SVG-графикой, синтезированным Web Audio звуком и плавными 60 FPS мини-играми.

---

## 🚀 Как собрать и получить готовый APK файл через GitHub Actions:

### Шаг 1: Создайте новый репозиторий на GitHub
1. Зайдите на [github.com/new](https://github.com/new).
2. Укажите название репозитория, например: `tamagotchi-p12`.
3. Сделайте его **Public** (или Private).
4. Нажмите **Create repository**.

### Шаг 2: Загрузите файлы проекта
**Способ А (Через браузер — самый простой):**
1. В созданном репозитории нажмите ссылку **uploading an existing file** (или перетащите файлы в браузер).
2. Распакуйте архив `Tamagotchi-P12-Source.zip` (или выделите все файлы и папки из этой директории).
3. Перетащите их мышкой в окно браузера на GitHub.
4. Нажмите зелёную кнопку **Commit changes**.

**Способ B (Через консоль Git):**
```bash
git init
git add .
git commit -m "Initial commit of Tamagotchi P12"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/tamagotchi-p12.git
git push -u origin main
```

---

### Шаг 3: Скачайте готовый APK файл
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. Вы увидите запущенный процесс: **Build Tamagotchi P12 APK**.
3. Дождитесь завершения сборки (~1-2 минуты) — появится зелёная галочка ✅.
4. Нажмите на строку завершённой сборки и прокрутите страницу вниз до блока **Artifacts**.
5. Скачайте архив **`Tamagotchi-P12-Debug-APK`**.
6. Внутри архива лежит готовый файл **`app-debug.apk`**!

---

## 📲 Установка APK на смарт-терминал Kozen P12:

Подключите терминал к компьютеру по USB и выполните команду:
```cmd
adb install -r app-debug.apk
```
Или скопируйте `app-debug.apk` на терминал и откройте его через любой стандартный проводник файлов.

На рабочем столе терминала появится иконка **«Тамагочи P12»**, запускающая игру в чистом аппаратном полноэкранном режиме (480×480)!
